# AstraSort AS-200 常见故障排查指南

> 本文档为虚构的设备运维资料，仅用于 OpsAtlas 项目演示。

## 1. 包裹在输送带上卡滞

### 现象

包裹停止移动、堆积，或输送带运行不顺畅。

### 排查步骤

1. 按下急停按钮，停止设备。
2. 确认设备完全停止后，移除卡滞包裹和异物。
3. 检查输送带是否跑偏、破损或张力不足。
4. 检查分拣挡板是否停留在异常位置。
5. 恢复运行前，使用测试包裹验证输送线是否正常。

如果卡滞反复发生，应由维修工程师检查输送带和驱动电机。

## 2. 包裹无法扫码

### 现象

包裹经过扫码区域后没有识别结果，或扫码失败率明显升高。

### 排查步骤

1. 检查包裹条码是否破损、褶皱或被遮挡。
2. 清洁扫码器镜面。
3. 检查扫码器的电源和通信线缆。
4. 使用测试条码验证扫码器功能。
5. 操作面板出现 E101 时，按照报警代码手册处理。

## 3. 称重结果不稳定

### 现象

同一个包裹多次通过时，称重结果变化明显。

### 排查步骤

1. 检查称重平台是否残留异物。
2. 确认包裹完全位于称重区域内。
3. 使用标准测试件进行复测。
4. 检查称重模块固定螺栓和连接线。
5. 出现 E310 时，暂停自动分拣并通知维修工程师。

## 4. 输送带电机温度过高

### 现象

电机外壳温度明显升高，或操作面板出现 E205 报警。

### 排查步骤

1. 立即停止设备运行。
2. 等待电机自然冷却，不得强行重启。
3. 检查输送带是否卡滞、负载是否过大。
4. 检查电机散热区域是否被遮挡。
5. 若报警重复出现，创建维修工单并通知维修工程师。
