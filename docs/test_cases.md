# OpsAtlas 测试问题集

本文档用于验证 OpsAtlas RAG 知识库的核心能力。

## 1. E205 报警处理

- 问题：设备出现 E205 时应如何处理？
- 预期：返回停止设备、等待自然冷却、检查卡滞/负载/散热、重复报警创建工单等步骤。
- 预期来源：`报警代码手册.md`、`常见故障排查指南.md` 或 `设备报警处理补充手册.pdf`。
- 验证重点：语义检索、步骤化回答、引用来源。

## 2. E101 报警处理

- 问题：E101 扫码器通信异常应如何排查？
- 预期：返回检查扫码器电源、通信线缆、镜面清洁状态，必要时通知维修工程师。
- 预期来源：`报警代码手册.md`、`设备报警处理补充手册.pdf`。
- 验证重点：报警代码与处理方案的关联检索。
- - 实际结果：Top 1 命中 `设备报警处理补充手册.pdf` 的 E101 条目，分数 0.8554；Top 2 命中 `报警代码手册.md` 的 E101 条目，分数 0.7732。
- 结论：通过。

## 3. 无资料兜底

- 问题：设备采购价格是多少？
- 预期回答：根据当前知识库资料无法确定。
- 预期来源：无。
- 验证重点：相似度阈值过滤，避免模型编造资料外内容。
- - 实际结果：检索结果经过 `MIN_SCORE = 0.55` 阈值过滤后，符合条件的资料数量为 0。
- 结论：通过。

## 4. PDF 页码溯源

- 问题：补充手册中 E205 的处理要点是什么？
- 预期：返回停止设备、自然冷却、检查卡滞/负载/散热区域、重复报警创建工单。
- 预期来源：`设备报警处理补充手册.pdf`，第 2 页。
- 验证重点：PDF 逐页解析、页码元数据、前端来源展示。
- - 实际结果：问题“E205 输送带电机过热应如何处理？”的 Top 1 命中 `设备报警处理补充手册.pdf` 中“二、E205 输送带电机过热”，相似度 0.8913，页码为第 2 页。
- 结论：通过。

## 5. 网页上传后入库

- 操作：网页上传一个新的 `.md`、`.txt` 或 `.pdf` 文件。
- 预期：页面显示上传成功以及最新文档记录数、Chunk 数量。
- 后续验证：针对新文档内容提问，应能检索并回答。
- 验证重点：`FormData` 上传、`POST /upload`、自动调用 `ingest()`、Milvus 更新。
